# MCP каталога Островка

Поддерживаемые города: Москва, Санкт-Петербург, Казань и Сочи. Сервер читает JSON-LD публичной страницы города. Возвращает название, адрес, рейтинг, фото и ссылку при наличии этих полей. Даты и число гостей валидируются для совместимости с CoDoc. Каталог возвращает `catalogOnly: true`, поскольку данные страницы не подтверждают наличие номеров и цены на выбранные даты.

Локальный запуск из этой папки — `python server.py`. Адрес для интеграционного теста — `http://127.0.0.1:8192/mcp`.

Для PostgreSQL-деплоя `CODOC_OSTROVOK_MCP_ENABLED=true` включает профиль `ostrovok-mcp`. Штатный deploy собирает образ по очереди с остальными и запускает MCP после остановки BuildKit. CoDoc использует `http://ostrovok-mcp:8192/mcp` и `search_hotels`. Порт внутри сети Compose, лимит 64 MiB и 0,15 CPU. Маршрут `/health` проверяет готовность процесса.

В локальной проверке MCP ответил на `initialize`, `tools/list` и `tools/call` с публичными данными Москвы. Отдельно проверен запрос каталога для каждого поддерживаемого города. Получено 9, 10, 9 и 8 карточек соответственно. Состав выдачи зависит от публичной страницы Островка.
