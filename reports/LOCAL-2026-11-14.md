# Локальная доработка 14 ноября 2026

## Что изменено

- Русскому интерфейсу добавлен выбор текущей карты или Яндекс Карт. Используется только JavaScript API: адреса и POI по-прежнему приходят из Photon/OSM/Wikimapia/2GIS. Метки связаны со списком, геометрия прогулки отображается на карте. Можно выбрать точку маршрута касанием; выбранная координата отмечается красным. При смене языка на другой Яндекс-вариант скрывается. Печатный документ сохраняет прежнюю карту OSM. Добавлены настройки браузерного ключа и CSP обеих конфигураций Nginx.
- Мистическая тема направлена в локальную таблицу и CSV: 173 исходных записи, без обращений к внешним POI-сервисам. Добавлены валидация, BOM/кавычки/переносы строк, пропуск ошибочных строк, повторный импорт без дублирования, ссылки на источники. Одинаковые координаты не повторяются в прогулке.
- Добавлены таблица исторических зданий, JTS-модель, API по координате и поиск рядом по адресу, архитектору или стилю. Исторические сведения дополняют описания POI; в отдельной прогулке появилась тема «Исторические дома». Описания и метаданные сохраняются в модели документа и выводятся в PDF. UI-подписи переведены на девять языков.
- Реализован GeoTools-импорт GeoPackage: чтение реальных колонок HOITH, преобразование EPSG:3857 → EPSG:4326, стабильные ID при отсутствии OSM ID, UPSERT пачками до 250 записей с дополнительным ограничением оценочного объёма. SQLite mmap ограничен 32 МБ, пул — одним соединением; исходник открывается только для чтения. Импорт включается явно. Для базы старых домов по умолчанию задан известный год постройки 1000–1945, доступны фильтр городов и повторная загрузка.
- В инфраструктуре подготовлены PostGIS-образ PostgreSQL 17 Alpine, миграции до запуска приложения, read-only каталог импорта, Linux/PowerShell-скрипты скачивания. Локальный профиль OAuth/JWT/Cookie сохранён; добавлен только путь CSV.
- Исправлен возрастной отбор стихов: для взрослых подборок учитывается явная детская жанровая маркировка издателя; детское произведение не возвращается через резервный источник после такого отказа. Старые неизменяемые подборки автоматически не переписываются.
- На странице решений сначала показаны три основных сценария; остальные доступны по категориям и поиску. Подробные преимущества раскрываются по желанию. Добавлены события Метрики без отправки текста поиска. Счётчики клиентов и отзывы не выдумывались.

## Что пока не подтверждено

Полная текущая Java-сборка остановилась на недоступности части GeoTools/SQLite/EMF-зависимостей: HTTPS-загрузки дали тайм-ауты. Поэтому полноценный GeoPackage-тест и полный `mvn verify` новой версии ещё не объявляются успешными. Нативный `PostgisPlacesTest` подготовлен для отдельной тестовой базы, но на реальном PostGIS в этой сессии не запускался.

Последние попытки SSH к серверу и GitHub завершались закрытием соединения или тайм-аутом до авторизации; HTTPS сайта также не отвечал из текущего окружения. **Изменения этого пакета ещё не отправлены в Git, не задеплоены; историческая база в PostgreSQL ещё не загружена.** Последнее разрешение пользователя на отправку, деплой и импорт действует: после восстановления доступа следует закончить зависимости и проверки, отправить все три репозитория, запустить только `ticket-infra/deploy.sh`, дождаться импорта и подтвердить SQL-количество строк, API и PDF.

Расширение на 500 + 500 + 500 новых мистических мест отложено по последнему указанию пользователя. Найденные поиском статьи не превращались в вымышленные 1500 записей. Текущее число 173 относится к объединённому пользовательскому CSV.

Серверное ядро поиска и UI имеют проверяемые результаты. Готовность к промышленной публикации пока не подтверждена: остаются полноценный GeoTools-прогон, нативный PostGIS, деплой и фактический импорт. Полную задачу считать завершённой до этих действий нельзя.
