# Сверка реализации с ТЗ сервиса маршрутов

Сверка относится к текущему исходному коду. Для прогулок применяется уточнение пользователя. Выделение области, поиск мест и планирование пешего маршрута находятся в приватном Journey. В CoDoc пользователь выбирает день и сохраняет готовый план, возвращённый из Journey.

| Фаза ТЗ | Что реализовано и проверено | Что осталось |
|---|---|---|
| 0–6. Аудит и рефакторинг | Инвентаризация, флаг планировщика, разделение части слоёв и репозиториев. ArchUnit проверяет границы домена | Полная сверка Javadoc, ADR и всех архитектурных правил ТЗ |
| 7. Данные v2 | Проекция исторического маршрута сохраняет геометрию и ссылки на фото. Локальный HTTP-тест подтверждает чтение и печать старого маршрута. Экспорт `v1-compat` возвращает оригинальный снимок | Проверка на копии целевой базы и согласование удаления данных после миграции при сохранении старых ссылок |
| 8. Приватный Journey | В браузере проверена передача готового маршрута из реальной сборки Journey в выбранный день CoDoc, включая мобильный размер окна | Приёмка на физических устройствах и целевой среде |
| 9. Карта поездки | Отметки городов, линейка, автомобильные переезды через промежуточные точки, карточки переезда и отеля | Полная приёмка карты и взаимодействий на мобильных устройствах |
| 10. Поставщики | Яндекс Расписания ответили на живой запрос расписания и справочника. Курсы Банка России загружаются из датированного XML. Есть адаптер Nominatim, собственный MCP каталога Островка и чтение нормализованной выгрузки Росаккредитации | Продакшен-ключ Яндекса в серверных секретах, согласованный экземпляр Nominatim, реальная выгрузка реестра. MCP каталога не подтверждает цены и наличие на даты |
| 11–12. План и проживание | Сохранение владельцем, сводка по дням, карточки, выбор проживания, фильтры по полям поставщика, маршрут до редактирования выбранного отеля | Проверка на реальных поставщиках и приёмка фильтров с живыми ценами |
| 13. Шаринг и экспорт | Публичная версия для чтения, файл для отправки, JSON, PDF и ICS. Серверные тесты проверяют владельца, текст PDF и разбор календаря | Пользовательская приёмка PDF и импорт ICS в целевые календари |
| 14. Выпуск | Штатный сценарий PostgreSQL-деплоя учитывает флаг фронтенда и ограниченный MCP. Сборка MCP входит в общий BuildKit | На целевом сервере оставалось 304 МБ свободного диска. Развёртывание, проверки после обновления и оценка SUS остаются открытыми |

До обновления штатные проверки работающего сайта подтвердили HTTP 200 для списка тематик и пешего маршрута. Браузерная проверка подтвердила, что карта записи Journey открывается с подложкой из кэша при отключённой сети. На сервере замерены 3915 MiB RAM, около 2424 MiB доступной памяти при работающих сервисах и отсутствие OOMKilled в текущих контейнерах.

Отдельное описание запуска и ограничений источника находится в [документации MCP](../mcp/ostrovok/README.md). Ресурсные ограничения описаны в [RESOURCE-BUDGET.md](../RESOURCE-BUDGET.md).
